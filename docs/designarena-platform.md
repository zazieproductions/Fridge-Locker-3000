# DesignArena platform: provenance and what was kept

## What DesignArena is

[DesignArena](https://designarena.ai) runs head-to-head tournaments in which
AI models generate complete web applications from the same prompt; visitors
vote, and an evaluation harness instruments the preview iframe with a
recorder, an element picker, and view analytics. Fridge Locker 3000 was
generated by **Gemini 3 Pro** in tournament `80e556b4-9284-4620-86fa-530415164713`
and exported as commit `543a0cd "Export from DesignArena (agon_webapps)"`.

## How to use the surviving platform tooling

The source-tags plugin + element picker pair is the one genuinely useful
platform leftover: hover any element in a tagged dev session and read off the
source file, line, and column.

```bash
SOURCE_TAGS=1 npm run dev
# then, in the browser console:
#   paste tools/designarena/element-picker/element-picker.vendor.js
#   press Alt+Shift+I  (or postMessage { type: 'inspect:mode', enabled: true })
```

Clicking an element logs `{ file, line, column, tag, text }` and posts it to
the parent frame for tooling integrations. The plugin stamps
`data-source-loc="file:line:col"` at compile time, so it never affects
production builds unless explicitly enabled there (don't).
